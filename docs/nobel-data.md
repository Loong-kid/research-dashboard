# 노벨상 수상 기록과 기여 문헌

검토일: 2026-10-21. 화면은 `#nobel?category=medicine&year=2012`처럼 분야와 연도를 공유할 수 있다.

1901~2026년 126개 연도, 세 분야의 수상·미수여 기록을 모두 포함한다. 고유 문헌은 837편, 확인한 무료 원문 링크는 119건이다. 같은 논문이 여러 수상자나 수상에 연결될 수 있다. 초기 수상 등 35건은 기여 문헌을 확인하지 못해 연결하지 않았다. 이 수치는 검토 당시 기준이며 공식 기록의 자동 갱신 날짜와 논문 선정 검토 날짜는 화면에서 구분한다.

## 출처와 연결 기준

1. **수상 기록:** [NobelPrize.org 공식 API](https://www.nobelprize.org/organization/developer-zone-2/). 상의 연도, 분야, 수상자 ID·이름, 지분, 공식 영문 수상 사유를 사용한다. 시상 시점이 연기된 경우에도 상의 연도를 유지한다. 한국어 제목 일부는 편집 요약이며 공식 번역으로 표시하지 않는다. [API 이용 조건](https://www.nobelprize.org/about/terms-of-use-for-api-nobelprize-org-and-data-nobelprize-org/)을 참고한다.
2. **과거 기여 문헌:** Li, Yin, Fortunato, Wang의 [Harvard Dataverse 데이터셋](https://doi.org/10.7910/DVN/6NJ5RN), 2018, CC0. [연구 설명](https://doi.org/10.1038/s41597-019-0033-6)에 따라 수상 성과와 연결된 기록을 가져오고, 출판 기록 파일의 Paper ID로 DOI를 결합했다. 1901~2016년 모든 수상자를 포괄하는 목록이 아니며 노벨 위원회 지정 목록도 아니다. 원자료 행 ID와 수상자 이름 표기 보정 근거를 보존한다.
3. **최근 수상 및 보완:** 공식 과학적 배경의 실제 인용 문헌을 대조해 추가했다. 2017~2026년은 각 수상자의 연결에 공식 근거를 제공한다. 링크는 해당 공식 페이지 또는 PDF의 실제 페이지 번호를 가리킨다. 인용 사실이 모든 문헌의 기여도가 같다는 의미는 아니다.
4. **서지·접근 정보:** [Crossref API](https://api.crossref.org/)의 출판사 제공 서지정보와 [Europe PMC API](https://europepmc.org/RestfulWebService)를 대조했다. 무료 원문 링크는 DOI가 일치하고 무료 접근 표시가 있는 주소 또는 출판사에서 확인한 주소만 제공한다. 무료 접근과 재배포 허용은 별개다. 무료 링크가 없다고 유료 전용으로 단정하지 않는다.

수상자와 논문 저자는 같지 않을 수 있다. 공동연구·실험 지휘 등의 관계는 선정 자료에 따라 연결하고, 저자 목록은 별도의 서지정보를 사용한다. 확인하지 못한 저자 이름이나 인용 수를 추측하지 않는다. 수상 후의 해설 등은 `role: retrospective`로 별도 표시할 수 있다. 수상 이전에도 원 연구가 아닌 후일 해설은 이 표시를 사용한다.

## 확인한 보정·제외

- Bohr의 *On the constitution of atoms and molecules*, DOI `10.1080/14786441308634993`: 원자료의 온라인 등록 연도 2009 대신 인쇄 출판 연도 1913을 사용했다.
- Heyrovský의 *Researches with dropping mercury cathode: Part II. The Polarograph*, DOI `10.1002/recl.19250440606`: 온라인 등록 연도 2010 대신 인쇄 출판 연도 1925를 사용했다.
- 1911년 Wien 수상에 연결된 ‘Wien’s displacement law’의 원자료 연도 1983은 해당 원문과 대조하지 못해 제외했다. 제외 행은 `excludedRecords`에 보존한다.
- Ekimov·Onushchenko의 양자 크기 효과 논문은 1981년 연구이며, DOI `10.1134/S0021364023130040`은 2023년 재출판판으로 연결된다. 화면에 판본 차이를 명시한다.
- 거든의 1962년 장 상피세포 핵 이식 원문은 DOI `10.1242/dev.10.4.622`와 공식 2012년 배경 문헌을 확인했다. 야마나카의 2006·2007년 원 연구와 함께 2012년 생리의학상에서 탐색할 수 있다.

## 파일과 갱신

| 파일 | 역할 |
| --- | --- |
| `config/nobel-papers.json` | 검토한 문헌·DOI·연결 수상자·선정 근거·예외·검토일 |
| `scripts/refresh_nobel.py` | 공식 수상 기록 갱신, 선정 목록 결합, 스키마 검증 |
| `public/data/nobel.json` | 브라우저용 정적 스냅샷 |
| `src/NobelWorkspace.jsx`, `src/nobel.css` | 연도·분야 탐색, 수상자 필터와 출처 안내 |
| `scripts/test_nobel.py`, `tests/nobel.spec.js` | 데이터 계약, 읽기·서재·모바일·검색 검증 |

```sh
npm run data:nobel
python scripts/test_nobel.py
npx playwright test tests/nobel.spec.js
```

수집기는 공식 API의 수상 기록만 자동 갱신하며 문헌을 수상자 이름으로 자동 추정하지 않는다. 새 수상은 문헌 검토 전까지 미연결 상태로 표시될 수 있다. 기존 연결의 수상자 ID가 맞지 않거나 부분 API 응답이면 갱신을 거부하고 이전 스냅샷을 유지한다. GitHub Actions는 갱신 실패를 경고하고 보존된 자료를 검증한 뒤 배포한다. 미래 수상의 문헌 검토가 끝나기 전에는 검토일 이후 연도를 문헌 완비 검사에 포함하지 않는다.

선정 문헌을 추가할 때에는 DOI·원 발표 연도·서지정보를 대조하고, `connections`에 공식 수상자 ID와 검토 가능한 선정 근거를 기록한 다음 스냅샷과 검증을 함께 갱신한다. 기존 문헌 ID는 서재·메모 보존을 위해 유지한다.

원문은 출판사·저장소에서 열고 기관 인증도 해당 제공처에서 진행한다. 인증 정보는 대시보드가 수집하지 않는다. 사이트가 제공하는 것은 서지·초록·출처와 외부 원문 링크이며, 유료 원문의 복제·전문 번역본 내장은 포함하지 않는다.
