[뇌과학 열기](https://loong-kid.github.io/research-dashboard/#neuroscience) · [기존 분야 지도](https://loong-kid.github.io/research-dashboard/#all)

- 영역 → 주제 → 완료된 12개월의 실제 월별 논문 수와 두 12개월 기간의 변화

- 사람·동물·계산모델·배양세포·무작위 대조시험 메타데이터, 공개 원문과 Nature 계열 필터
- Nature의 공식 뇌과학 목록·저널 피드에서 확인한 Research Highlights·News & Views, 참고 연구 링크
- 주제별 읽기 질문과 용어, 선별 논문 12편의 초록 기반 한국어 읽기 노트
- 기존 서재·메모·Markdown 내보내기와 통합

범위와 동의어는 `config/neuroscience.json`, 수집기는 `scripts/refresh_neuroscience.py`입니다. [Europe PMC / PubMed API](https://europepmc.org/RestfulWebService)를 사용합니다. 제목 검색과 일부 초록 조건으로 관련성을 좁히며, 뇌과학 전체 문헌을 포괄하지 않습니다. 논문 수는 리뷰도 포함한 검색 결과 수이며 목록과 구분됩니다. MeSH·출판 유형에 없는 연구 대상은 추측하지 않습니다. 최신 논문은 색인·인용·대상 정보 반영이 늦을 수 있습니다.

성장률은 연구 활동량의 변화입니다. 직전 기간 20편 미만이면 비율을 표시하지 않습니다. 인용은 수집 당시의 누적 수이며 분야·연령 보정이나 임상 유효성 평가가 아닙니다. 원 연구 목록은 출판 유형과 제목의 review/meta-analysis 표기를 제외하지만 출판사 분류의 정확성을 보장하지 않습니다. 전체 분야의 발전 속도나 인기 순위라고 해석할 수 없습니다.

`scripts/refresh_editorial.py`가 [Nature의 뇌과학 주제 페이지](https://www.nature.com/subjects/neuroscience)에서 편집 해설 유형을 직접 확인합니다. 목록 페이지를 읽을 수 없으면 공식 뇌과학·Nature Neuroscience·Nature Reviews Neuroscience RSS에서 후보를 얻고 각 글의 `article-category / dc.type` 메타데이터로 편집 해설을 확인합니다. 이전에 확인한 최근 60일 글은 개별 확인 날짜를 유지해 함께 보여줄 수 있으며 각 글에 목록 출처를 표시합니다. 이 페이지의 전체 뇌과학 목록을 표시하며 12개 주제 필터는 적용하지 않습니다. 참고 연구는 해당 해설의 참고문헌 링크로, 대표 원 연구 한 편을 자동 판별한 것이 아닙니다. 표지·다운로드 순위는 수집하지 않습니다. 무료 읽기 링크와 재사용 라이선스는 다르므로 원문 조건을 확인해야 합니다.

한국어 읽기 노트는 `public/data/neuroscience-notes.json`의 수동 해설입니다. 저자 초록의 질문·방법·결과를 정리하고 설계에 따른 해석의 한계를 덧붙였습니다. 본문 검토나 자동 AI 요약은 아닙니다. 원문 링크와 작성일을 표시하며, 이후 목록에서 빠지는 논문도 읽기 가이드에서 볼 수 있게 별도 보관합니다. 다른 분야의 OpenAlex 통계와 뇌과학 통계는 서로 다른 관측 범위로 비교·합산하지 않습니다.

## 첫 버전

- 실제 OpenAlex 검색 결과로 만든 12개 주제의 연구 지도
- 최근 12개월 논문 수, 직전 12개월 대비 변화, 두 기간의 논문 수 비교
- 분야별 탐색, 논문 검색, 공개 원문 및 Nature 계열 필터
- 인용 수·발표일·FWCI 정렬 (수집한 논문 목록 내)
- 저자 초록, DOI·공개 원문 링크, 브라우저 내 서재·읽기 메모
- 서재 Markdown 내보내기, 모바일 메뉴, 키보드 접근, 모달 포커스 관리

기존 분야의 Nature 표시는 저널명 기준의 게재 정보입니다. 자동 한국어 AI 해설, 표지 선정, 임상 검증 단계 평가, 특허·산업 연결은 아직 구현하지 않았습니다.

## 데이터와 해석

`scripts/refresh_data.py`가 OpenAlex를 조회하고 `public/data/snapshot.json`에 저장합니다. 추적 검색어는 스크립트의 `TOPICS`에 있습니다. 논문 제목에서 영문 구문을 검색하며 `type:article`과 `is_retracted:false` 필터를 적용합니다. 저널 유형 분류나 철회 정보가 완벽함을 뜻하지 않습니다.

각 주제에서 최근 12개월 누적 인용 상위 최대 4편을 수집합니다. 검색·최신순·Nature 필터는 이 유한한 목록에서 동작합니다. 학문 전체 또는 실시간 논문 전체에 대한 순위가 아닙니다. 신규 논문은 인용과 색인 반영이 늦을 수 있습니다.

주제별 통계에는 중복 논문이 포함될 수 있습니다. 논문 목록은 OpenAlex ID로 중복 제거합니다. 성장률은 연구 활동량의 변화이며 학문적 진보·연구 품질·투자 가치를 직접 측정하지 않습니다. 원문 접근은 각 출판사·저장소의 이용 조건과 이용자 구독에 따릅니다. 초록과 서지정보의 누락은 화면에 표시합니다.

데이터 출처: [OpenAlex](https://openalex.org/), [인용 지표 안내](https://help.openalex.org/data/works/citations/). 배포 화면에서 수집 시각·비교 기간·검색어를 확인할 수 있습니다.

## 실행

Node.js 24, Python 3.13 이상을 권장합니다.

```sh
npm ci
npm run dev
npm run build
npm run data:refresh
pip install -r scripts/requirements.txt
npm run data:neuroscience
npm run data:editorial
```

특정 관측 기준일을 재현하려면:

```sh
python scripts/refresh_data.py --as-of 2026-10-08
```

선택적으로 `OPENALEX_API_KEY`를 환경변수 또는 GitHub Actions repository secret에 설정할 수 있습니다. 키는 브라우저 코드·JSON·로그에 저장하지 않습니다. API 인증·한도 정책이 바뀌면 secret을 설정하세요. 데이터 수집이 실패하면 기존 스냅샷과 기준일을 보존합니다.

## 배포와 갱신

GitHub Pages를 GitHub Actions 소스로 설정합니다. `main` push와 수동 실행, 매일 한국시간 오전 9시 20분 예약 실행으로 데이터를 새로 수집한 뒤 배포합니다. GitHub 예약 실행은 지연될 수 있습니다. 예약 실행은 원본 저장소의 스냅샷 파일을 커밋하지 않고 배포 산출물의 데이터를 갱신합니다. 장기간 저장소 활동이 없으면 GitHub의 정책에 따라 예약 실행이 중단될 수 있습니다.

서재·메모는 localStorage에만 보관하며 다른 기기와 동기화하지 않습니다. 기기 변경·브라우저 데이터 삭제 전에 내보내기를 사용하세요.

뇌과학과 Nature는 키 없이 수집합니다. 각 소스는 별도로 갱신하고, 실패하면 마지막 배포 데이터(유효한 경우) 또는 저장소의 스냅샷과 원래 날짜를 유지합니다. Nature 페이지 구조가 바뀌면 경고를 남기고 이전 목록을 유지합니다. 수집 후 데이터 계약 검증에 실패하면 배포가 중단됩니다. 새 분야는 뇌과학의 수집·탐색·읽기 흐름을 확인한 다음 별도 분류 설정과 소스 어댑터로 추가하는 방향입니다.
